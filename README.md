Employee Attendance Tracker
Project Overview
This is a practical Human Resource Management project developed using Microsoft Excel.The purpose of this project is to manage employee attendance, leave records, and absenteeism in an organized way.

Project Objectives
Maintain employee attendance records.
Track sick leave and casual leave.
Identify employee absences.
Calculate attendance summaries.
Support HR reporting and decision-making.

Tools Used
Microsoft Excel
COUNTIF formulas
Conditional Formatting
Data Validation
Excel Dashboard
Key Features
Employee attendance records
Leave management
Absence tracking
Automated attendance calculations
Attendance summary dashboard
Learning Outcomes
This project demonstrates practical skills in HR data management, Excel reporting, and basic HR analytics.

Disclaimer
This is an educational project using sample data. No confidential employee information is included.
